## 5. Workflow notes / lessons

* **Wikimedia Commons API** хорошо работает при указании **User-Agent** в форме `Mozilla/5.0 (compatible; ResearchArchiveBot/1.0; +https://example.com/research)`. Generic UA отвергается (403).
* **Cyrillic URL** ломаются, если их писать напрямую в `.bat` файле — CMD интерпретирует `%XX` как переменные. Решение: либо вызывать `curl` напрямую в shell, либо escape `%` как `%%` в batch.
* **Сохранение реальной лицензии каждого файла обязательно.** Не следует автоматически считать все Commons-файлы public domain — в категориях встречаются файлы под CC BY 4.0, CC BY-SA 4.0, CC BY 3.0, которые требуют атрибуции.
* **SHA-256-хеши** всех скачанных файлов зафиксированы в `scripts/validate/hashes.txt` (через PowerShell `Get-FileHash`). Использовался `certutil -hashfile`, но filter output required additional care under cmd.exe.
* **Парсинг JSON через cmd.exe неудобен** — использовались `grep_search` для извлечения URL через жёсткие регулярные выражения.
* **Хеш дубликатов:** на текущей фазе не обнаружены — все скачанные файлы имеют distinct hash и content. Готовы к сравнению при добавлении новых источников.
