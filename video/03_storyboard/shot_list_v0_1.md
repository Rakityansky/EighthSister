## Как читать этот документ

- **VO** — привязка к фразе дикторского текста.
- **Тип** — откуда берётся изображение / как производится кадр.
- **Asset / source** — какой источник нужен.
- **Action** — что именно должно происходить в кадре.
- **Priority** — насколько кадр критичен для первой версии ролика.

Условные обозначения типа кадра:
- `ARCHIVE` — историческое фото / эскиз / документ.
- `PHOTO` — современная фотография / съёмка.
- `MGFX` — motion graphics / карта / типографика / схема.
- `AI-IMG` — отдельно сгенерированное изображение.
- `AI-VID` — image-to-video / start-end-frame / transformation.
- `COMP` — compositing / сопоставление нескольких источников.

## Минимальный набор обязательных ассетов для v0.1

### Архив / фото
1. Московские высотки — 3–4 usable изображения.
2. Материал по восьмой высотке в Зарядье — 1–2 изображения.
3. Дом Гинзбурга — минимум 1 хороший исторический вид + 1 фото разрушений/послевоенного участка.
4. Разрушенный Крещатик — 1–2 изображения.
5. 3–5 конкурсных/послевоенных киевских высотных проектов.
6. Современный КГГА — минимум 2 ракурса.
7. Проект гостиницы «Москва» / «Украина» — минимум 2 стадии.
8. Крещатик, 25 — 1 изображение.

### Motion graphics
1. Карта центра Киева с высотными точками.
2. Мини-таймлайн 1944 → 1955.
3. Текстовые карточки: `1947`, `1955`, `22/24 этажа`, `≈137 м`.

### AI generation
1. **Master reconstruction image** высотного Крещатика, 36.
2. Ещё 2–3 согласованных ракурса этого же здания.
3. 1 концептуальный skyline альтернативного Киева.
4. 2 transformation shots:
   - реальный КГГА → высотный проект;
   - финальный повтор трансформации.

## Что можно упростить, если не хватает времени

Если нужно срочно собрать первый animatic, можно временно убрать или сильно сократить:
- Shot 12–13 (отдельные конкурсные проекты 1944);
- Shot 24–26 (часть второстепенных высотных проектов);
- Shot 29–30 (развёрнутый блок про 1955 и таймлайн).

Тогда ролик будет держаться на позвоночнике:
**1–5 → 6–10 → 15–21 → 23 → 27–28 → 31–33**.
